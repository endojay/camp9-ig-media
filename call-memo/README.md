# 전화 메모

진료시간 외에 걸려온 전화를 PC가 대신 받아 안내 멘트를 들려주고, 환자가 남긴 음성을 메모로 저장하는 윈도우용 프로그램입니다.

## 사용 방법

1. `dist/전화메모.exe` 를 PC의 원하는 폴더(예: `C:\전화메모`)에 복사해 실행합니다. 설치 과정은 없습니다.
2. 브라우저에 화면이 열립니다. 주소는 `http://127.0.0.1:8765` 이며 이 PC에서만 열립니다.
3. **설정** 탭에서 인터넷전화 계정, 진료시간, 안내 멘트를 입력하고 저장합니다.
4. 오른쪽 위 상태가 "자동응답 대기 중" 또는 "진료시간 (받지 않음)" 이면 정상입니다.
5. 아침에 **메모** 탭에서 녹음을 듣고, 콜백한 뒤 "콜백 완료" 를 누릅니다.

창을 닫아도 프로그램은 계속 실행됩니다. 끄려면 설정 탭 맨 아래 "프로그램 종료" 를 누릅니다.

## 먼저 준비할 것

- **SIP 계정**: 통신사에서 서버 주소, 사용자 ID, 인증 ID, 비밀번호를 받아야 합니다.
  통신사 전용 전화기에만 계정이 들어 있고 고객에게 알려주지 않는 상품이라면 이 프로그램을 직접 연결할 수 없습니다.
  그 경우 SIP 계정을 제공하는 070 번호를 하나 만들고, 진료시간 외에 대표번호를 그 번호로 착신전환하는 방법이 있습니다.
- **PC**: 밤새 켜져 있어야 하며 절전 모드로 들어가면 전화를 받지 못합니다.
- **방화벽**: 처음 실행할 때 윈도우 방화벽이 물으면 "허용" 을 선택합니다.

## 동작 방식

- 진료시간에는 전화를 받지 않고 원내 전화기가 울리도록 둡니다.
- 진료시간 외에는 설정한 시간(기본 3초) 뒤에 받아 안내 멘트 → "삐" → 녹음 순으로 진행합니다.
- 말이 없는 상태가 이어지거나(기본 8초) 최대 녹음 시간(기본 2분)이 되면 끊습니다.
- 음성을 남기지 않고 끊은 전화도 번호와 시각이 부재중 기록으로 남습니다.

## 저장 위치와 개인정보

메모, 녹음, 설정은 `%AppData%\Camp9CallMemo` 폴더에 저장됩니다. 녹음에는 환자 음성과 연락처가 들어 있으므로
PC 로그인 암호를 걸어 두고, 이 폴더를 주기적으로 백업하며, 오래된 메모는 삭제해 주세요.
SIP 비밀번호는 이 폴더의 `config.json` 에 암호화되지 않은 채 저장됩니다.

"음성을 글자로 바꾸기" 는 기본으로 꺼져 있습니다. 켜면 녹음 파일이 설정한 외부 서비스로 전송됩니다.
